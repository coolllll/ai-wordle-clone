# Proposal

## Why

ผู้ที่เข้าสู่ระบบเห็นเฉพาะประวัติเกมของตัวเอง จึงเทียบไม่ได้ว่าชัยชนะที่ดีที่สุดของตนอยู่ตรงไหนเมื่อเทียบกับบัญชีอื่น เกมชนะมีคะแนนเป็นจำนวนครั้งที่ทายอยู่แล้ว แต่ยังไม่มีหน้าที่รวบรวมคะแนนนั้นของทุกบัญชี

## What Changes

- เพิ่มหน้า `/leaderboard` สำหรับผู้ที่เข้าสู่ระบบ ลิงก์ Leaderboard อยู่ในแถบนำทางคู่กับ History และหัวข้อบนหน้าใช้คำเดียวกัน
- คนที่ไม่มีเซสชันเปิดหน้านี้แล้วถูกส่งไปหน้า login
- แต่ละบัญชีมีคะแนนเดียว คือจำนวนครั้งที่ทายในเกมที่ชนะด้วยจำนวนครั้งน้อยที่สุด ยิ่งน้อยยิ่งอยู่อันดับสูง แสดงเฉพาะบัญชีที่มีอย่างน้อยหนึ่งชัยชนะ
- คะแนนเท่ากันให้บัญชีที่บันทึกชัยชนะนั้นไว้ก่อนอยู่สูงกว่า ถ้าเวลาเท่ากันเรียงตามชื่อผู้ใช้ที่เก็บไว้ อันดับเป็น 1, 2, 3 ไม่ใช้เลขซ้ำ
- แต่ละแถวแสดงอันดับ ชื่อผู้ใช้ และคะแนนนั้น ไม่แสดงคำตอบหรือรายการคำทาย
- โหลดรายการตอนเปิดหน้า ไม่อัปเดตเองระหว่างที่หน้าเปิดอยู่
- ถ้ายังไม่มีผู้ชนะ หน้าเปิดได้และรายการว่าง
- ถ้าโหลดไม่สำเร็จ แสดงข้อความว่าโหลดไม่สำเร็จและไม่แสดงรายการ
- หน้าเกมไม่แสดงอันดับ หน้าประวัติยังแสดงเฉพาะเกมของบัญชีตัวเอง

สมมติฐาน: ข้อความผิดพลาดบนหน้าเป็นภาษาอังกฤษให้เข้ากับ UI เดิม โดยความหมายคือโหลด leaderboard ไม่สำเร็จ

## Capabilities

### New Capabilities

- `leaderboard`: หน้าอันดับคะแนนชัยชนะที่ดีที่สุดของทุกบัญชีสำหรับผู้ที่เข้าสู่ระบบ

### Modified Capabilities

- ไม่มี requirement ของ spec เดิมเปลี่ยน `score-history` ยังเป็นการดูประวัติของบัญชีตัวเอง และ `player-auth` ยังกำหนดเซสชันของหน้าเกมกับหน้าประวัติ การกันหน้า leaderboard ไว้ใน capability ใหม่

## Impact

- `src/components/AppShell.tsx` เพิ่มลิงก์ Leaderboard
- หน้า `/leaderboard` ภายใต้กลุ่มเส้นทางที่มีเซสชัน
- ฟังก์ชันจัดอันดับจากเกมที่ชนะและชื่อผู้ใช้ในที่เก็บเดิม
- ไม่เปลี่ยนการบันทึกคะแนน การเปิด `GET /api/history` หรือรายการบนหน้าเกม
