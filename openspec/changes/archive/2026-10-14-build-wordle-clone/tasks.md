# Tasks

## 1. ตั้งค่าแอปพลิเคชัน

- [x] 1.1 สร้างโครงโปรเจกต์ Next.js App Router พร้อม TypeScript, linting และโครงสร้าง source directory แล้วตรวจสอบว่า development server แสดงหน้าเริ่มต้นได้
- [x] 1.2 ติดตั้งและตั้งค่า Tailwind CSS กับ daisyUI พร้อม theme ของแอป แล้วตรวจสอบว่า component ของ daisyUI แสดงผลด้วย theme ที่เลือก
- [x] 1.3 ตั้งค่าเครื่องมือสำหรับ unit test และ component test พร้อม smoke test แล้วตรวจสอบว่าคำสั่ง test ทำงานสำเร็จ

## 2. กติกาเกมและข้อมูลคำศัพท์

- [x] 2.1 เพิ่มรายการคำตอบและคำที่อนุญาตให้ทายในรูปแบบ JSON พร้อม typed loading และ normalization แล้วตรวจสอบด้วย test ว่าข้อมูลผิดรูปแบบ คำซ้ำ และคำที่ไม่ได้มีห้าตัวอักษรถูกปฏิเสธ
- [x] 2.2 สร้าง pure function สำหรับประเมินตัวอักษรซ้ำ โดยตรวจ exact match ก่อน present match แล้วตรวจสอบด้วย unit test ให้ครอบคลุม correct, present, absent และตัวอักษรซ้ำที่เกินจำนวนในคำตอบ
- [x] 2.3 สร้างการเริ่มเกม การตรวจสอบคำทาย การนับจำนวนครั้ง คะแนน และการเปลี่ยนสถานะชนะหรือแพ้ แล้วตรวจสอบด้วย unit test ให้ครอบคลุมคำทายที่ไม่ถูกต้อง การชนะในครั้งที่ 1 ถึง 6 และการแพ้ในครั้งที่ 6
- [x] 2.4 สร้าง public game projection ที่ซ่อนคำตอบของเกมที่ยังเล่นอยู่และเปิดเผยคำตอบเมื่อเกมจบ แล้วตรวจสอบด้วย serialization test ว่าคำตอบของเกมที่ยังเล่นไม่ถูกเปิดเผย

## 3. การบันทึกข้อมูลใน JSON บนเครื่อง

- [x] 3.1 กำหนดและตรวจสอบ schema ของข้อมูลเกมที่บันทึก พร้อมการสร้างไฟล์ว่างอย่างปลอดภัย แล้วตรวจสอบด้วย storage test ว่าโหลดข้อมูลว่างและข้อมูลที่ถูกต้องได้
- [x] 3.2 สร้างการเขียน JSON แบบ serialized และ atomic ด้วยการแทนที่ temporary file แล้วตรวจสอบด้วย test ใน temporary directory ว่าข้อมูลเดิมยังคงอยู่เมื่อเขียนไฟล์ล้มเหลว
- [x] 3.3 บันทึกเกมที่กำลังเล่นและเกมที่จบแล้วโดยให้การจบเกมเป็นแบบ idempotent แล้วตรวจสอบด้วย test การ restart และการจบเกมซ้ำว่าแต่ละเกมมี durable record เพียงรายการเดียว
- [x] 3.4 สร้าง history projection ที่เรียงจากใหม่ไปเก่า โดยเกมที่ชนะใช้จำนวนครั้งที่ทายเป็นคะแนนและเกมที่แพ้ไม่มีคะแนน แล้วตรวจสอบด้วย storage test ให้ครอบคลุมลำดับและผลลัพธ์ทั้งสองแบบ

## 4. Server API

- [x] 4.1 เพิ่ม Route Handler สำหรับสร้างเกมและสุ่มคำตอบ แล้วตรวจสอบด้วย API test ว่า response เป็น public game ใหม่ที่ไม่มีคำตอบ
- [x] 4.2 เพิ่ม Route Handlers สำหรับดึงข้อมูลเกมและส่งคำทาย พร้อม input validation และ error response ที่ชัดเจน แล้วตรวจสอบด้วย API test ให้ครอบคลุมการกู้คืนเกม คำทายที่ถูกต้อง คำทายที่ไม่ถูกต้อง เกมที่ไม่พบ และเกมที่จบแล้ว
- [x] 4.3 เพิ่ม Route Handler สำหรับประวัติ แล้วตรวจสอบด้วย API test ว่า response มีรายการเกมที่จบแล้วเรียงจากใหม่ไปเก่าและมีข้อมูลที่กำหนดครบถ้วน
- [x] 4.4 แปลง storage failure เป็น API error ที่ปลอดภัยโดยไม่เขียนทับข้อมูลที่ถูกต้อง แล้วตรวจสอบด้วย API test ว่าระบบไม่รายงานว่าสำเร็จเมื่อบันทึกข้อมูลล้มเหลว

## 5. UI สำหรับเล่นเกม

- [x] 5.1 สร้าง page shell, กระดานเกม และสถานะ tile ด้วย daisyUI ให้รองรับหลายขนาดหน้าจอ แล้วตรวจสอบด้วย component test ว่าแสดงหกแถว แถวละห้าช่อง โดยไม่มี horizontal overflow บน viewport ขนาดเล็ก
- [x] 5.2 สร้าง input state ที่ใช้ร่วมกันสำหรับ physical keyboard และ on-screen keyboard รวมถึง delete, submit, การจำกัดความยาว และการป้องกัน input ระหว่างรอ แล้วตรวจสอบด้วย component test ให้ครอบคลุม input ทั้งสองแบบ
- [x] 5.3 เชื่อมการสร้างเกม การกู้คืนเกม และการส่งคำทายเข้ากับ API แล้วตรวจสอบด้วย component integration test ให้ครอบคลุมการเริ่มเกม reload หน้า และเล่นเกมต่อ
- [x] 5.4 แสดง validation error, tile feedback, สถานะ keyboard และผลชนะหรือแพ้ แล้วตรวจสอบด้วย component test ให้ครอบคลุมคำที่ไม่ถูกต้อง คำทายที่ชนะ และคำทายครั้งที่หกที่ทำให้แพ้
- [x] 5.5 เพิ่ม flow “เกมใหม่” แบบไม่จำกัดหลังเกมจบ แล้วตรวจสอบว่าสามารถเริ่มเกมต่อเนื่องได้โดยไม่ต้อง refresh หน้า
