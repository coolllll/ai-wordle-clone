# Proposal

## Why

เกมเก็บประวัติไว้ชุดเดียวและเปิดหน้าเกมได้โดยไม่ต้องระบุตัวผู้เล่น เมื่อมีหลายคนใช้เครื่องหรือเซิร์ฟเวอร์เดียวกัน ผลเกมจึงปนกัน และไม่มีทางแยกประวัติของแต่ละคน

## What Changes

- ผู้ใช้ต้องเข้าสู่ระบบก่อนถึงหน้าเกมและหน้าประวัติ ผู้ที่ยังไม่มีเซสชันจะเห็นหน้า login
- หน้า login ใช้โครงแบบหน้าอ้างอิง: พื้นขาวเต็มจอ การ์ดกลางจอประมาณ 400px โลโก้ ช่อง Username และ Password ปุ่มเต็มความกว้าง และ footer ปรับข้อความและโลโก้เป็นของ Word Guess ไม่ใช้บัญชี MFA หรือแบรนด์ของ Warroom
- ผู้ใช้สร้างบัญชีใหม่ได้จากการ์ดรูปแบบเดียวกัน เพราะตอนนี้ยังไม่มีบัญชีในระบบ
- แต่ละบัญชีมีประวัติเกมของตัวเอง และเห็นเฉพาะเกมที่ตนเองเป็นเจ้าของ
- **BREAKING** การเปิดหน้าเกมหรือหน้าประวัติโดยไม่เข้าสู่ระบบใช้ไม่ได้อีกต่อไป เรคอร์ดเก่าใน `games.json` ที่ไม่มีเจ้าของจะไม่ถูกแสดงให้บัญชีใด

สมมติฐาน: บัญชีและเซสชันอยู่บนเซิร์ฟเวอร์ของแอปนี้ รหัสผ่านถูกเก็บแบบแฮช ไม่เชื่อมระบบล็อกอินภายนอก กฎการทายคำไม่เปลี่ยน

## Capabilities

### New Capabilities

- `player-auth`: สร้างบัญชี เข้าสู่ระบบ และเปิดหน้าเกมกับหน้าประวัติเฉพาะเมื่อมีเซสชันของผู้ใช้คนนั้น

### Modified Capabilities

- `score-history`: ประวัติที่บันทึกและที่แสดงเป็นของผู้ใช้ที่เข้าสู่ระบบเท่านั้น ไม่ใช่ประวัติรวมของทุกเกมในไฟล์

## Impact

- เส้นทางหน้าแรก หน้าประวัติ และ API ของเกมกับประวัติต้องรู้ว่าคำขอเป็นของผู้ใช้คนใด
- ที่เก็บ JSON ต้องมีบัญชีและเจ้าของของแต่ละเกม
- เทสต์ของหน้าเกม ประวัติ และ API ที่ตอนนี้เรียกโดยไม่มีผู้ใช้ต้องเข้าสู่ระบบก่อน
- กฎใน `wordle-gameplay` ไม่เปลี่ยนเมื่อผู้ใช้เข้าสู่ระบบแล้ว
