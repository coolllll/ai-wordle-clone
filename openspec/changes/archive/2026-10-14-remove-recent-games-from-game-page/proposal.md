# Proposal

## Why

หน้าเกมแสดงรายการ Recent games ใต้กระดาน ทั้งที่หน้า `/history` แสดงเกมที่จบแล้วชุดเดียวกันอยู่แล้ว รายการซ้ำนี้ทำให้หน้าเล่นยาวขึ้นและดึงประวัติทุกครั้งที่เปิดเกม โดยไม่ได้ให้ข้อมูลที่หน้าประวัติยังไม่มี

## What Changes

- เอาส่วน Recent games และรายการเกมที่จบแล้วออกจากหน้าเกม
- ให้การดูวันที่ ผลลัพธ์ คะแนน คำตอบ และคำทายของเกมที่จบแล้วยังอยู่ที่หน้าประวัติเท่านั้น
- หน้าเกมยังแสดงสถานะของเกมที่กำลังเล่นหรือเพิ่งจบ รวมถึงปุ่มเริ่มเกมใหม่ และลิงก์ History ในส่วนหัว
- เลิกให้หน้าเกมเรียกข้อมูลประวัติมาแสดง การบันทึกประวัติและ `GET /api/history` สำหรับหน้าประวัติยังคงอยู่

สมมติฐาน: “recent game” หมายถึงส่วน `history-panel` ที่หัวข้อ Recent games ไม่ใช่ข้อความชนะหรือแพ้ของเกมปัจจุบัน change `multiplayer-login` ที่ยังไม่เสร็จเป็นคนกำหนดว่าประวัติเป็นของบัญชีใด change นี้ไม่เปลี่ยนการแยกบัญชี

## Capabilities

### New Capabilities

- ไม่มี

### Modified Capabilities

- `score-history`: การดูประวัติเกมที่จบแล้วยังเป็นมุมมองเรียงจากใหม่ไปเก่า แต่ไม่อยู่บนหน้าเกมอีกต่อไป หน้าเกมต้องไม่แสดงรายการนั้น และต้องไม่เรียก `GET /api/history` ทั้งตอนเปิดหน้าและตอนจบเกม การขอรายการประวัติเกิดเมื่อเปิดหน้า history เท่านั้น

## Impact

- `src/components/GameClient.tsx` และเทสต์ที่คาดว่ารายการประวัติโผล่บนหน้าเกม
- `src/lib/client-api.ts` ถ้า `fetchHistory` ไม่มีผู้เรียกเหลือหลังถอดการแสดงผลออก
- หน้า `/history`, `HistoryList`, การบันทึก JSON และกฎการเล่นไม่เปลี่ยนพฤติกรรมที่ spec กำหนดไว้
