# Tasks

## 1. บัญชี

- [ ] 1.1 เพิ่มที่เก็บ `data/users.json` และฟังก์ชันสร้างบัญชีด้วย username ที่ไม่ซ้ำ พร้อมแฮชรหัสผ่านด้วย `scrypt` ตรวจว่าเทสต์สร้างบัญชีใหม่ได้ และ username ซ้ำไม่สร้างบัญชีเพิ่ม
- [ ] 1.2 เพิ่มการตรวจ username กับรหัสผ่านตอนเข้าสู่ระบบ ตรวจว่าเทสต์ผ่านเมื่อรหัสถูก และไม่ผ่านเมื่อ username หรือรหัสผิดโดยไม่คืนรหัสผ่าน

## 2. เซสชัน

- [ ] 2.1 ออกคุกกี้ `httpOnly` ที่ลงลายเซ็นแล้วหลังสร้างบัญชีหรือเข้าสู่ระบบ และอ่านรหัสบัญชีจากคุกกี้นั้นได้ ตรวจว่าเทสต์ยอมรับคุกกี้ที่ลงลายเซ็นด้วยคีย์ปัจจุบัน และปฏิเสธคุกกี้ที่ถูกแก้
- [ ] 2.2 ลบเซสชันเมื่อออกจากระบบ ตรวจว่าหลังออกจากระบบคำขอถัดไปไม่มีบัญชี

## 3. เจ้าของเกมและประวัติ

- [ ] 3.1 ให้เกมที่สร้างใหม่เก็บ `userId` ของบัญชีที่เข้าสู่ระบบ และให้อ่านหรือทายได้เฉพาะเกมของบัญชีนั้น ตรวจว่าเทสต์ของบริการเกมผ่านสำหรับเจ้าของ และไม่คืนคำตอบหรือสถานะของเกมคนอื่น
- [ ] 3.2 ให้ `toHistory` และ `GET /api/history` คืนเฉพาะเกมที่จบของบัญชีนั้น โดยไม่รวมเกมที่ไม่มี `userId` ตรวจว่า `src/lib/history.test.ts` และเทสต์ API ประวัติผ่านเมื่อสองบัญชีมีผลคนละชุด

## 4. หน้า login และทางเข้า

- [ ] 4.1 สร้าง `/login` และ `/register` เป็นหน้าพื้นขาวเต็มจอ การ์ดกลางประมาณ 400px ชื่อ Word Guess ช่อง Username กับ Password ปุ่มเต็มแถว และ footer โดยไม่ใช้ shell ของเกม ตรวจว่าเทสต์หน้า login เห็นโครงนี้ และแสดงข้อความเมื่อเข้าสู่ระบบไม่สำเร็จ
- [ ] 4.2 ส่งผู้ไม่มีเซสชันจาก `/` และ `/history` ไป `/login` และให้ `AppShell` แสดงชื่อผู้ใช้กับปุ่มออกจากระบบเมื่อมีเซสชัน ตรวจว่าเทสต์เปิดหน้าเกมโดยไม่มีเซสชันแล้วไม่เห็นกระดาน
